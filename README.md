# Lyra

🎵 Tu música, tu dispositivo, tus reglas. Reproductor libre, multiplataforma y adaptable.

## Fase 3.4 — Catálogo abierto y fuentes de reproducción

Lyra **ya no depende de Jamendo** ni de Spotify Premium. `Explorar` utiliza MusicBrainz
para descubrir grabaciones y permite reproducir archivos locales o fuentes HTTPS directas
que el usuario está autorizado a escuchar.

Un resultado de MusicBrainz no equivale a un flujo de audio; no existe una fuente
única que garantice escuchar todo el catálogo mundial.

Consulta [`LEEME_LYRA_3_4_FUENTES.md`](LEEME_LYRA_3_4_FUENTES.md) para instalar y probar.

La sección de playlists de YouTube sigue siendo opcional y de solo lectura.
